# AppsUsageMonitor dependency

This directory contains source from the open-source AppsUsageMonitorAPI project:

https://github.com/TheBotBox/AppsUsageMonitorAPI

Upstream project: TheBotBox/AppsUsageMonitorAPI
Library module: appusagemonitor
Original published version used by this application: 2.1.0

The source is vendored here because the original JCenter-hosted binary
dependency is no longer reliably retrievable by modern builds.
